PROJECT 01SEARCH · STATE SPACES

Maze Solver with Keys & Doors

Find a way out. Remember what you collect.

A maze is more than a grid when a locked door changes where you can go. Explore how a search tracks both your position and the keys in your inventory.

S → key → door → EState = position + inventory
01 / INPUT
A square maze with walls, a start, an exit, and up to six key types. Type it, import CSV, or generate a maze.
02 / APPROACH
BFS, DFS, Dijkstra, and A* explore position + key-bitmask states. BFS, Dijkstra, and A* find shortest routes; DFS may take a longer one.
03 / EXPLORE
Replay the frontier, rejected moves, key pickups, and final route. Scrub backward or export the marked path.
BFS / DFSDijkstra / A*Key bitmasks

PROJECT 02GEOMETRY · DIVIDE & CONQUER

Closest Pair of Points

Find the closest two in a crowd.

Compare checking every pair with an approach that splits the plane, solves smaller problems, and checks a narrow strip between them.

Split → solve → mergeTwo approaches. One minimum distance.
01 / INPUT
A set of 2D points, entered manually, imported from CSV, or generated for an experiment.
02 / APPROACH
Compare O(n²) brute force with O(n log n) divide and conquer. Sorted strip checks catch pairs that cross the split.
03 / EXPLORE
Watch recursive partitions and candidate comparisons. See the nearest pair and distance, then compare measured running times.
Divide & conquerO(n log n)Brute-force baseline

PROJECT 03GRAPHS · DYNAMIC PROGRAMMING

Cheapest Flights with Coupons

A smarter route for a smaller fare.

The cheapest journey depends on where you fly, how many stops you make, and when you spend a discount coupon.

City × flights × couponsOptimize the route and the discounts.
01 / INPUT
A directed flight network, a maximum number of intermediate stops, and a budget of half-price coupons.
02 / APPROACH
Layered dynamic programming tracks city, flights taken, and coupons used. Each flight can be paid in full or discounted once, rounding down.
03 / EXPLORE
Follow the aircraft along the chosen route. Inspect ticket costs, coupon usage, running totals, and export the itinerary as CSV.
Layered DPStop constraintsCoupon decisions

PROJECT 04OPTIMIZATION · GRAPH COLORING

Exam Scheduling

Fewer slots. No exam clashes.

Turn shared-student conflicts into a graph and build a timetable that respects both course conflicts and the number of available halls.

Conflicts → colors → timetableOne color per slot. One exam per hall.
01 / INPUT
Courses, pairs that cannot run together, and the maximum number of exams allowed in a time slot.
02 / APPROACH
Capacity-aware DSatur builds a greedy schedule. Exact branch and bound searches for improvements and reports whether optimality is proven within its time budget.
03 / EXPLORE
Watch courses receive slots, compare greedy and exact schedules, inspect the conflict graph, and download a hall-by-hall CSV timetable.
DSatur greedyBranch & boundHall capacity
