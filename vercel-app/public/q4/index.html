GRAPH COLORING, WITH HALL LIMITS

Conflicting exams need different slots.

A node represents a course. An edge means two courses share a student and cannot take the same slot. Each slot holds at most R exams; a column in the timetable is one available hall.

DSatur greedy selects the course touching the most distinct assigned slots, breaks ties by conflict degree and then course ID, and uses the first compatible slot with space.

Branch-and-bound starts with the greedy timetable and explores compatible assignments to find improvements. It prunes branches using capacity and lower bounds and avoids permuting empty slot labels.

Proven optimal means the slot count matches a valid lower bound or exhaustive search has ruled out every smaller timetable. If the budget expires first, the result is a valid best found timetable, not a proven minimum. The displayed lower bound gives a limit on any possible improvement. A greedy result can also be certified by the exact run.

Click either algorithm card to start its assignment replay. The graph and grid use matching slot colors. Assignments are replayed from the returned timetable; this is not an animation of every failed exact-search branch. CSV exports the full timetable even when playback is paused.

The comparison chart uses freshly generated graphs and measured times. Hollow markers identify unfinished exact searches. Runtime varies with graph difficulty, system load. Each sample is one run; small timing differences are not statistically meaningful.

Inputs support 0–60 courses and 1–20 halls in the browser. N = 0 needs zero slots. Self-conflicts are rejected; repeated or reversed conflict rows are merged.
